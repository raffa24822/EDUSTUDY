📘 Tutorial Sinkronisasi

Ikuti panduan singkat ini:

  1. Tekan Atur Server / Sinkronisasi.
  2. Portal akan terhubung otomatis ke server jika dibuka dari link publik yang sama.
  3. Siswa dapat langsung masuk dengan nama; akun dan aktivitas akan dikirim ke server secara otomatis.
  4. Setelah konfigurasi tersimpan di perangkat ini, siswa bisa masuk seperti biasa. Guru masuk menggunakan username dan password guru.

Penting: Tidak perlu mengatur sinkronisasi dari akun siswa. Jika status gagal, pemilik portal perlu memastikan server Render aktif dan file HTML/server berasal dari versi yang sama.

❓ FAQ

Bagaimana menambah soal dengan keyboard?

Masuk ke Bank Soal lalu gunakan Enter untuk berpindah dari teks soal ke pilihan, kunci jawaban, pembahasan, dan simpan.

Apakah soal yang dibuat Guru langsung muncul di siswa?

Ya, perubahan bank soal disinkronkan pada tab atau jendela portal yang menggunakan penyimpanan browser yang sama.

Bagaimana memantau pengerjaan siswa?

Gunakan tab Monitor Siswa pada dashboard Guru untuk melihat status dan jumlah pelanggaran yang tercatat.
