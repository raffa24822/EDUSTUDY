EDUSTUDY — REVISI LOGIN, SESI, DAN PENILAIAN ESAI

PERUBAHAN
1. Menghapus panel pemeriksaan manual esai pada dashboard guru.
2. Esai dinilai otomatis: 3 kata kunci = benar; 2 kata kunci = benar; 1 atau 0 = salah.
3. Menambahkan reservasi USN global pada edustudy/studentUsernames agar USN yang sudah terpakai tidak dapat didaftarkan oleh UID siswa lain.
4. Mempertahankan Firebase Auth Local Persistence dan sesi siswa pada browser/perangkat yang sama. Refresh/menutup lalu membuka kembali website seharusnya memulihkan UID anonim dan profil siswa.

PENTING — BATAS ANONYMOUS AUTHENTICATION
Akun anonim Firebase tidak dapat dipulihkan hanya dengan mengetik USN di perangkat lain. USN bukan kredensial autentikasi. Jika siswa menghapus data browser, memakai perangkat lain, atau kehilangan sesi anonim, akun lama tidak dapat diambil alih hanya dengan USN. Untuk pemulihan lintas perangkat dibutuhkan password, nomor/email, atau backend tepercaya yang mengeluarkan custom token.

PENTING — FIREBASE RULES UNTUK INDEKS USN
Fitur reservasi USN menulis ke /edustudy/studentUsernames/{usn_normalized}. Firebase Realtime Database Rules harus mengizinkan pengguna terautentikasi membaca/menulis node tersebut agar transaction dapat bekerja. Jangan membuka seluruh database. Atur hanya node studentUsernames dan uji aksesnya. Perlu diingat, jika .read diberikan kepada semua auth user, daftar pasangan USN-UID dapat dibaca pengguna terautentikasi; untuk privasi lebih kuat, pindahkan reservasi username ke Cloud Functions/backend tepercaya.

PEMASANGAN
1. Backup index.html lama.
2. Ganti index.html di root repository GitHub dengan file ini.
3. Commit perubahan dan tunggu deployment Vercel Ready.
4. Pastikan Firebase Authentication > Sign-in method > Anonymous tetap aktif.
5. Pastikan Firebase Auth persistence tidak dibersihkan oleh kode lain.
6. Uji: daftar USN baru; coba daftar USN sama dari browser lain (harus ditolak setelah Rules index aktif); refresh; tutup dan buka kembali browser yang sama.

CATATAN
JavaScript inline diperiksa sintaks. Belum dilakukan pengujian live terhadap Firebase Rules, Firebase Auth, atau Vercel.
