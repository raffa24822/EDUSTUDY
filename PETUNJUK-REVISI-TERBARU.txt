EDUSTUDY - REVISI LANJUTAN

PERUBAHAN
1. Pemulihan sesi siswa: jika Firebase Anonymous Auth masih menyimpan user dan profil UID masih ada, aplikasi mencoba memulihkan sesi siswa secara otomatis. Data browser/cache tidak boleh dihapus dan siswa tidak boleh logout.
2. Tombol Reset Semua Akun pada dashboard guru menghapus seluruh profil siswa pada Realtime Database, termasuk nilai, jawaban esai, dan catatan pelanggaran.
3. Isian singkat: benar jika kata kunci tunggal muncul sebagai kata/frasa utuh dalam jawaban; selain itu salah.
4. Esai: 3 kata kunci disimpan sebagai benar, 2 kata kunci juga benar, 1 atau 0 salah. Guru dapat melihat jawaban, kata kunci, dan menimpa keputusan benar/salah; rekap nilai diperbarui ketika keputusan guru berubah.
5. Kartu pengumuman siswa dibuat lebih ringkas dan terstruktur.

CATATAN RESET AKUN
Reset Semua Akun menghapus profil dan data terkait di Realtime Database, bukan menghapus record Anonymous Authentication Firebase. Menghapus akun Auth secara massal membutuhkan Firebase Admin SDK/backend tepercaya; jangan meletakkan service-account key di index.html. Setelah reset, akun anonim yang masih ada di browser tidak memiliki profil sampai didaftarkan kembali.

CATATAN SESI
Anonymous Authentication LOCAL persistence dapat memulihkan sesi pada browser/perangkat yang sama. Sesi tidak dapat dijamin bertahan jika siswa menekan Logout, menghapus data situs/cookies, memakai mode incognito, browser lain, atau perangkat lain.

PEMASANGAN
1. Backup index.html lama.
2. Ganti index.html di root repository GitHub dengan file ini.
3. Commit ke branch utama dan tunggu Vercel Deployment Ready.
4. Uji login guru, siswa, reload halaman, tutup-buka browser, reset akun, submit esai/isian, keputusan guru, dan tampilan pengumuman.

PEMERIKSAAN
Inline JavaScript lolos node --check. Belum dilakukan uji runtime Firebase/Vercel pada akun proyek.
